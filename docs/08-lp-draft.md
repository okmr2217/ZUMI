# ZUMI（済） LP下書き

> 実装（`apps/web/app/landing.tsx`）と同じ構成・コピーに揃えたマークダウン版。
>
> **2026/11 改訂の方針**: 訴求の核は「毎日のことも定期的なことも、シンプルに管理できる」こと。柱は2つで、①やったら「済」を押すだけ、②やっていなければ通知が教えてくれる。ZUMI の起点は「毎日続けようと思ったことが意外と続かない → 続けられる仕組みをつくる」で、定期的なタスク管理はあとからついてきたもの。この順で伝わるよう、ヒーロー → つくった理由（しくみは2つだけ）→ 通知 → 毎日も定期的も → 振り返り → CTA の順に組み替えた。旧構成にあった「デイリー画面（日付を送って過去を記録）」の節は、核から外れる細部なので外した。
>
> 「続ける」を前に出しても、ストリーク（連続記録日数）は扱わない方針は変えない。「途切れても責めない」をつくった理由の節で明言する。
>
> 例に「お風呂」は使わない（「毎日入れない」前提に読まれ、非常識に見えるおそれがあるため）。「前回から◯日」の例は水回り掃除・洗濯槽の掃除・シーツ交換にする。

## ZUMI をつくった理由 — 続けようと決めたことが、意外と続かない。

プロテインも、英語の勉強も、筋トレも。
始めるときは本気なのに、気づくと何日も空いている。

足りなかったのは、意志ではありませんでした。
やったかどうかを残しておく場所と、忘れたときに思い出させてくれる仕組み。
ZUMIは、それをつくるところから始まっています。

### しくみは、2つだけ。

1. **やったら、「済」を押す。** 書くことも、数えることもありません。朱印をワンタップすれば、その日の分は記録されます。
2. **やっていなければ、教えてくれる。** まだ済んでいないものは、夜に通知が教えてくれます。忘れていたことを、寝る前に拾えます。

何日続いたかは数えません。途切れても、また次の日に押せばいい。

---

## 通知 — やっていないことを、夜に教えてくれる。

朝は、今日やる分をまとめて1通。夜は、まだ済んでいないものだけをもう1通。
済ませたものは載らないので、全部済ませた日の夜は何も届きません。

- 「前回から◯日」のものは、日が空いてきたら「そろそろ」として届きます
- 「週に2回」のものは、このままだと今週に間に合わなくなる日から届きます
- 届くのは1日に最大2通。通知が多すぎて全部切ってしまう、を防ぎます

*(朝・夜の通知の見本 + 「全部『済』にした日は、夜の通知は届きません」 + 設定画面の見本)*

iPhone では、ZUMI をホーム画面に追加すると通知が届くようになります。

> 通知の中身は docs/02 の仕様どおり（夜は済・スキップ済みを除く、対象ゼロなら送らない、`SINCE_LAST` は催促中のみ、`WEEKLY_COUNT` は残回数 ≥ 残り日数から）。仕様を変えたらここも直す。

## 毎日も、定期的も — 毎日のことも、定期的なことも、ひとつの場所で。

毎日続けたいことのために作った仕組みは、ゴミ出しや月イチの掃除のような「定期的にやってくること」にも、そのまま使えます。
なりたい自分のためでも、やらなきゃいけないことでもかまいません。

*（以下は例示。LP にはこのうち9件をカードで並べる。テンプレートから選ぶことも、自由入力で追加することもできる）*

**🗑️ ゴミ出し**
- 可燃・不燃・資源ゴミ（曜日が決まってるやつ）

**🧴 からだ**
- プロテイン・サプリ摂取（毎日摂りたいけど忘れる）

**🏠 住まいのメンテ**
- 換気扇・レンジフード掃除（月イチくらいで十分）
- エアコンフィルター掃除（月イチくらいで十分）
- 洗濯槽の掃除（気づくと数ヶ月放置しがち）
- 掃除機のフィルター・ヘッド掃除
- 水回り（排水口）掃除（サボりがちだけど放置できない）
- シーツ・タオル交換（気づくと1ヶ月経ってる）

**💰 暮らしの手続き**
- サブスク・固定費の見直し（月イチで棚卸し）

**📖 自分磨き**
- 語学学習（週◯回のペースを保ちたい）
- 筋トレ・ランニング（週◯回など、ペースを決めておきたい）
- 読書（月に1冊は読みたい）
- 日記・振り返りの時間（週に数回、自分と向き合う）

### 期日パターン — 「変な周期」も、ちゃんと設定できる。

「隔週の資源ゴミ」も、「シーツ、前回替えてから2週間経ったら」も、同じアプリの中で扱えます。

**決まっているもの**
- 毎日
- 曜日を指定（月・木だけ、など）
- 週に◯回
- 月に1回

**なんとなく空いたら**
- 前回やってから◯日経ったら（そろそろ）

「そろそろ」は、シーツ交換や水回り掃除のような、起点を固定すると破綻する活動と相性がいい設定です。

## 振り返り — 今週どれだけ済ませたかを、成績表みたいに受け取る。

連続記録（ストリーク）は競いません。サボった週があっても、先週との差分だけ見えればいい。

**週次サマリー（主役）— 今週の「済」具合が、1枚のカードで届く。**
毎週、達成した数と先週との差分が届きます。済んだものも未達のものも隠さず並び、そのままシェア画像として保存・投稿できます。

**月次カレンダー（小さく添える）— 続いていることを、濃淡で眺める。**
1ヶ月分のマスに、その日の達成度を敷いていきます。タップすれば、その日の記録を開けます。

**履歴（小さく添える）— 済ませたことも、スキップしたことも残る。**
日付ごとに並べて記録します。Duty名で絞り込んで、過去に遡ることもできます。

# ZUMI（済） - 画面構成

> 関連: [Duty管理・記録・振り返り・アカウント](./03-duty-log-review-account.md)

## 4. 画面構成

```
Bottom Tab（3つ）
├── 今日        今日やるべき Duty と押印
├── 振り返り     週次サマリー・ヒートマップ・履歴
└── Duty        Duty の追加・編集・DnD並び替え

設定は「今日」タブ右上の歯車からモーダルで開く（タブを消費しない）
```

Habito の5タブ（ホーム／記録／統計／活動／設定）から3タブに圧縮する。摩擦の低さを売るアプリでタブが5つあると、それ自体が認知負荷になる。

### 4-1. 今日

上部に日付と今日の進捗バー（X / Y）。その下に **3セクション**で Duty を並べる。

| セクション | 対象 | 表示 |
|---|---|---|
| 今日 | 期日確定型で今日が期日のもの | — |
| そろそろ | `SINCE_LAST` で催促が発生しているもの | 「最後から2日」。警告色で区別 |
| 今週 | `WEEKLY_COUNT` で残回数があるもの | 「あと1回・日曜まで」 |

- 各行の右端にある空円をタップした瞬間に朱印が押されて完了。**記録モーダルは開かない**
- 長押しで詳細モーダル（対象日変更・スキップ・メモ）
- 完了済みは最下部に「済んだもの N件」として折りたたむ

**「そろそろ」を独立させる理由**: `SINCE_LAST` を「今日」に混ぜると、風呂が毎日「今日やるべきこと」として出続け、ユーザーが折れるパターンに戻ってしまう。催促が発生してから初めて現れ、済ませたら消える、という挙動を視覚的にも分離する。

### 4-2. 振り返り

上から順に、週次サマリーカード（＝そのままシェア画像）、月次カレンダーヒートマップ、日付グループの履歴リスト。1スクロールで完結させる。

Habito の「記録」タブと「統計」タブを統合する。シェアカードを最初に目に入る位置に置きたいため。別タブに埋めると誰も開かず、シェアが発生しない。

- ヒートマップは Duty 選択で切り替え（全体 / 個別）
- 履歴は絵文字ではなくアイコン・名前・DONE/SKIP バッジ・メモをインライン表示
- 無限スクロールで過去に遡る。無料プランは直近3ヶ月まで

### 4-3. Duty

- カード一覧。DnD（`@dnd-kit/sortable`）で並び替え → `sortOrder` をまとめて PATCH
- 各カードに編集・一時停止・アーカイブ
- 追加時は**テンプレート一覧が先**に出て、自由入力はその下に置く
- 編集フォームは名前・アイコン・繰り返しタイプ・前夜通知・メモ欄の有無

### 4-4. 設定（モーダル）

- アカウント: メールアドレス変更・パスワード変更・退会
- 通知: 許可ボタン、朝／夜／週次サマリーの ON/OFF と時刻、タイムゾーン
- データ: エクスポート
- ヘルプ: 繰り返し設定の説明など

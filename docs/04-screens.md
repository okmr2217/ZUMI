# ZUMI（済） - 画面構成

> 関連: [Duty管理・記録・振り返り・アカウント](./03-duty-log-review-account.md)

## 4. 画面構成

```
Bottom Tab（3つ）
├── デイリー     指定日の Duty 一覧と押印（過去・今日・未来を行き来できる）
├── 振り返り     週次サマリー／月次ヒートマップ／履歴の3ページ（サブタブ切り替え）
└── Duty        Duty の追加・編集・DnD並び替え

設定は「デイリー」タブ右上の歯車からモーダルで開く（タブを消費しない）
```

Habito の5タブ（ホーム／記録／統計／活動／設定）から3タブに圧縮する。摩擦の低さを売るアプリでタブが5つあると、それ自体が認知負荷になる。

### 4-1. デイリー

**タブ名について**: 当初「今日」としていたが、過去日・未来日にも遷移できる仕様のため、当日限定を想起させる名前は実態と合わない。日付をまたいで同じ画面構成を使い回すことを示す「デイリー」に変更する。

上部に日付ヘッダー（前日／翌日への矢印 or スワイプで対象日を切り替え）。**対象日にかかわらず進捗バー（X / Y）を表示する**。過去日への遡り記録・未来日の予定確認、どちらも同じ画面で完結させる。

| 対象日 | 進捗バーの意味 | 朱印操作 |
|---|---|---|
| 今日 | 現時点での進捗（X件済 / Y件） | タップで完了 |
| 過去日 | その日の実績（何件済ませたか） | タップで遡り記録・修正が可能（既存仕様） |
| 未来日 | その日時点で期日を迎える予定件数 | 押印不可（グレーアウト表示のみ。先取り完了は許可しない） |

日付ヘッダーの進捗バーは常に同じ位置・同じ見た目で表示し、「今日を見ているのか過去を見ているのか」を進捗バー上部の日付ラベルとバーの色（今日のみ朱色、過去・未来はグレー基調）で区別する。

その下に **3セクション**で Duty を並べる（未来日はこの3セクション構成のまま「予定」として表示、そろそろ／今週セクションは未来日では非表示）。

| セクション | 対象 | 表示 |
|---|---|---|
| 今日 | 期日確定型でその日が期日のもの | — |
| そろそろ | `SINCE_LAST` で催促が発生しているもの | 「最後から2日」。警告色で区別。今日のみ表示 |
| 今週 | `WEEKLY_COUNT` で残回数があるもの | 「あと1回・日曜まで」。今日のみ表示 |

- 各行の右端にある空円をタップした瞬間に朱印が押されて完了。**記録モーダルは開かない**
- 長押しで詳細モーダル（対象日変更・スキップ・メモ）
- 完了済みは最下部に「済んだもの N件」として折りたたむ

**「そろそろ」を独立させる理由**: `SINCE_LAST` を「今日」に混ぜると、風呂が毎日「今日やるべきこと」として出続け、ユーザーが折れるパターンに戻ってしまう。催促が発生してから初めて現れ、済ませたら消える、という挙動を視覚的にも分離する。

### 4-2. 振り返り

週次サマリー・月次ヒートマップ・履歴を**3つのサブページ**に分け、上部のセグメントコントロールで切り替える構成にする。

**変更の経緯**: 当初は3つを縦に並べて1スクロールで完結させる設計だったが、月次ヒートマップ（5週×7日のグリッド）と履歴リスト（無限スクロール）を同じスクロール軸に積むと、画面の高さに収まらずヒートマップや履歴が実質的に見えない・気づかれない状態になる。3つとも見せたい情報の密度が高いため、1ページに集約せず分割する。

| サブページ | 内容 |
|---|---|
| 週次サマリー | 達成率・前週比・朱印の並び（＝そのままシェア画像）。振り返りタブを開いたときの初期表示 |
| 月次ヒートマップ | カレンダー形式の濃淡表示。Duty 選択で切り替え（全体 / 個別） |
| 履歴 | 日付グループのリスト。Duty 名での絞り込み、無限スクロール |

Habito の「記録」タブと「統計」タブを統合する形は維持しつつ、内部をサブタブで分ける。週次サマリーを初期表示にするのは、シェアカードを最初に目に入る位置に置きたいため。別タブの奥に埋めると誰も開かず、シェアが発生しない。

- 履歴は絵文字ではなくアイコン・名前・DONE/SKIP バッジ・メモをインライン表示
- 無限スクロールで過去に遡る。無料プランは直近3ヶ月まで

### 4-3. Duty

- カード一覧。DnD（`@dnd-kit/sortable`）で並び替え → `sortOrder` をまとめて PATCH
- 各カードに編集・一時停止・アーカイブ
- 追加時は**テンプレート一覧が先**に出て、自由入力はその下に置く
- 編集フォームは名前・アイコン・繰り返しタイプ・前夜通知・メモ欄の有無

### 4-4. 設定（モーダル）

- アカウント: メールアドレス変更・パスワード変更・退会
- 通知: 許可ボタン、朝／夜／週次サマリーの ON/OFF と時刻、タイムゾーン
- データ: エクスポート
- ヘルプ: 繰り返し設定の説明など

# ZUMI（済） - 画面構成

> 関連: [Duty管理・記録・振り返り・アカウント](./03-duty-log-review-account.md)

## 4. 画面構成

```
Bottom Tab（3つ）
├── 今日        今日やるべき Duty と押印
├── 振り返り     週次サマリー・ヒートマップ・履歴
└── Duty        Duty の追加・編集・DnD並び替え

設定は「今日」タブ右上の歯車からモーダルで開く（タブを消費しない）
```

Habito の5タブ（ホーム／記録／統計／活動／設定）から3タブに圧縮する。摩擦の低さを売るアプリでタブが5つあると、それ自体が認知負荷になる。

### 4-1. 今日

上部に**日付ナビゲーション**（‹ 日付 ›）と今日の進捗バー（X / Y）。その下に **3セクション**で Duty を並べる。

| セクション | 対象 | 表示 |
|---|---|---|
| 今日 | 期日確定型で今日が期日のもの | — |
| そろそろ | `SINCE_LAST` で催促が発生しているもの | 「最後から2日」。警告色で区別 |
| 今週 | `WEEKLY_COUNT` で残回数があるもの | 「あと1回・日曜まで」 |

- 各行の右端にある空円をタップした瞬間に朱印が押されて完了。**記録モーダルは開かない**
- 長押しで詳細モーダル（対象日変更・スキップ・メモ）
- 完了済みは最下部に「済んだもの N件」として折りたたむ

**「そろそろ」を独立させる理由**: `SINCE_LAST` を「今日」に混ぜると、風呂が毎日「今日やるべきこと」として出続け、ユーザーが折れるパターンに戻ってしまう。催促が発生してから初めて現れ、済ませたら消える、という挙動を視覚的にも分離する。

**日付ナビゲーション（過去日・未来日の表示）**: ヘッダーの ‹ › で前後の日に移動できる。「振り返り」の月次ヒートマップの日付セルをタップした場合も同じ画面に該当日を開いた状態で遷移する。

| 表示している日 | タイトル | 完了操作 | 備考 |
|---|---|---|---|
| 今日 | 「今日」 | 可（朱印タップ） | 通常状態 |
| 過去日 | 「過去の記録」 | 可（未記録の項目も遡ってタップで記録できる） | 3-3の「過去日への遡り記録」に対応。ヘッダー下に「今日へ戻る」ピルを表示 |
| 未来日 | 「予定の確認」 | 不可（タップ対象は鍵アイコンの読み取り専用表示） | 「済」にできるのはその日になってから。ヘッダー下に「今日へ戻る」ピルを表示 |

### 4-2. 振り返り

上から順に、週次サマリーカード（＝そのままシェア画像）、月次カレンダーヒートマップ、日付グループの履歴リスト。1スクロールで完結させる。それぞれのブロックは月次ヒートマップと同じ体裁の見出し（セクションラベル）を上に置き、ブロックの境目を揃える。

Habito の「記録」タブと「統計」タブを統合する。シェアカードを最初に目に入る位置に置きたいため。別タブに埋めると誰も開かず、シェアが発生しない。

**週次サマリー**

- 見出し「週次サマリー」の右に共有ボタンを配置し、カード自体（＝シェア画像）をその場で共有シートに送出できるようにする。見出しから最短距離で共有導線に届く設計とし、カードの中に埋め込んだアイコンなどには頼らない
- カードの内容は範囲＋週番号、達成率＋前週比バッジ、Duty ごとの内訳（朱印／未達は破線バッジ）、フッターのブランド表記の構成（詳細は[振り返り・シェア](./03-duty-log-review-account.md#3-4-振り返りシェア)）

**月次カレンダーヒートマップ**

- ヒートマップは Duty 選択で切り替え（全体 / 個別）
- 各日付セルに達成度の濃淡に加えて「完了数/母数」（例: 4/5）を表示する。データのない日（登録前・当月未到来）は「–」
- セルをタップすると、その日付を開いた状態で「今日」画面に遷移する（4-1 の日付ナビゲーション参照。未来日は「予定の確認」、過去日は「過去の記録」として開く）

**履歴**

- 絵文字ではなくアイコン・名前・DONE/SKIP バッジ・メモをインライン表示
- 無限スクロールで過去に遡る。無料プランは直近3ヶ月まで

### 4-3. Duty

- カード一覧。DnD（`@dnd-kit/sortable`）で並び替え → `sortOrder` をまとめて PATCH
- 各カードに編集・一時停止・アーカイブ
- 追加時は**テンプレート一覧が先**に出て、自由入力はその下に置く
- 編集フォームは名前・アイコン・繰り返しタイプ・前夜通知・メモ欄の有無

**追加・編集ダイアログ（モーダル）**

下から出るシートで、追加・編集ともに同じフォーム構成を使う。

| 項目 | 追加 | 編集 |
|---|---|---|
| テンプレート | 冒頭に横並びのチップで表示。選ぶと下のフォームに初期値が入る | 出さない（既存の値がそのまま入っている） |
| 名前 | プレースホルダー付き自由入力 | 既存値を表示 |
| アイコン | プリセットを横スクロールの一覧から選択 | 同左 |
| 繰り返し | [第1段階の5択](./03-duty-log-review-account.md#繰り返しタイプの選択ui自由入力時) → 選択に応じた詳細設定（曜日トグル・日数ステッパーなど） | 同左。既存の設定を選択状態で表示 |
| プレビュー | 「次の期日：8/28（金）」のように設定結果をリアルタイム表示 | 同左 |
| 前夜通知・メモ欄 | トグル2つ | 同左 |
| 保存操作 | 「追加する」ボタン | 「保存する」ボタン。加えて「一時停止する」「アーカイブする」をボタン下に配置 |

### 4-4. 設定（モーダル）

- アカウント: メールアドレス変更・パスワード変更・退会
- 通知: 許可ボタン、朝／夜／週次サマリーそれぞれに ON/OFF トグルと時刻設定（タップで開く時刻ピッカー）を1行ずつ配置。タイムゾーンも保持
- 表示: 週次サマリー・月次ヒートマップの基準となる「週の始まり」（曜日）を指定
- データ: エクスポート
- ヘルプ: 繰り返し設定の説明など

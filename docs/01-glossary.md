# ZUMI（済） - 用語定義

> 関連: [プロダクト概要](./00-overview.md) / [Duty管理・記録・振り返り・アカウント](./03-duty-log-review-account.md)

## 2. 用語定義

| 用語 | 説明 |
|---|---|
| Duty | ユーザーが登録する義務的活動の単位。Habito の Activity に相当 |
| ログ（Log） | Duty に対して1対象日に1回行う「済／スキップ」の記録 |
| 対象日 | 記録が紐づく日付。実際に操作した日時（記録日時）とは別に設定可能 |
| 期日確定型 | 日付がカレンダーから決まる Duty（DAILY / WEEKDAYS / NTH_WEEK / MONTHLY） |
| 期日不確定型 | 日付が決まらない Duty（WEEKLY_COUNT / SINCE_LAST） |
| 催促 | 期日不確定型で「そろそろやるべき」状態に入ること |

**注記（用語の運用）**

- 「催促」は内部状態を指すバックエンド用語であり、ユーザー向け画面には出さない。UI上は必ず「そろそろ」等の言い換えを介す
- 「Duty」もDB／コード上の名称として維持する。ユーザー向けの呼称（オンボーディングやLPでの言い回し）は別途コピーライティング時に検討し、この用語集とは切り離して管理する
